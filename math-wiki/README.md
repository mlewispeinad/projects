This project analyzes public engagement with mathematics by examining page view data from over 1,000 math-related Wikipedia pages collected between 2019 and 2021. I contributed by developing interactive visualizations through a Shiny app to help users explore page views over time. Additionally, I created heatmaps to display average views by weekday and month, and generated bar charts showing the top 50 most connected pages in the Wikipedia math network. These tools enhance understanding of how different math topics capture public interest and how external events influence online attention.
